Главная О работе Особенности Студент

О практическом задании

Данная веб-страница разработана в рамках задания №3 средней сложности. Она демонстрирует отдачу статических HTML-документов с подключением внешнего каскадного стиля CSS через механизм url_for в микрофреймворке Flask.

Преимущества подхода

Сепарация слоев

Разделение разметки HTML и стилевого оформления CSS обеспечивает чистоту архитектуры и повторное использование компонентов.

Адаптивность

Использование CSS Grid и Flexbox позволяет верстке плавно масштабироваться под экраны любых устройств.

Статический сервер

Flask автоматически настраивает маршрут /static/ для раздачи стилевых файлов, скриптов и изображений с кэшированием.
